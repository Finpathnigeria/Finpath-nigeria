# FinPath Nigeria — PWA Setup & Deployment Guide

## Project Structure
```
finpath-pwa/
├── public/
│   ├── index.html          ← PWA-ready HTML (meta tags, splash, manifest link)
│   ├── manifest.json       ← Web App Manifest (icons, name, shortcuts)
│   ├── service-worker.js   ← Offline caching, push notifications, background sync
│   ├── offline.html        ← Shown when user is offline with no cache
│   └── icons/              ← App icons (SVGs provided, convert to PNG — see below)
├── src/
│   ├── index.js            ← React entry, service worker registration, splash hide
│   ├── App.jsx             ← PWA prompts wrapper
│   ├── FinPath.jsx         ← Your main app (from Claude)
│   ├── usePWA.js           ← Custom hook: install prompt, updates, push, online status
│   ├── PWAPrompts.jsx      ← Install banner, update banner, offline bar, push prompt
│   └── serviceWorkerRegistration.js  ← SW lifecycle management
├── generate-icons.js       ← Generates SVG icons (run: node generate-icons.js)
└── package.json
```

## STEP 2 — Convert Icons to PNG (Required for PWA)

The SVG icons are in `public/icons/`. You need PNG versions.

**Easiest method — RealFaviconGenerator (free, online):**
1. Go to https://realfavicongenerator.net
2. Upload `public/icons/icon-master.svg`
3. Customise — keep background #0B3D2E (dark green)
4. Download the package
5. Replace files in `public/icons/` with the downloaded PNGs
6. Copy the `favicon.ico` to `public/`

**Alternative — using Sharp (Node.js):**
```bash
npm install sharp --save-dev
node convert-icons.js  # (create this file using the Sharp snippet below)
```

Sharp snippet for convert-icons.js:
```javascript
const sharp = require('sharp');
const sizes = [72,96,128,144,152,192,384,512];
sizes.forEach(s => {
  sharp(`public/icons/icon-${s}x${s}.svg`)
    .resize(s, s)
    .png()
    .toFile(`public/icons/icon-${s}x${s}.png`);
});
```

## STEP 6 — Connect Custom Domain (Optional)

1. Buy domain at Namecheap (~$10/yr) or QServers.com (Nigerian registrar, accepts ₦)
2. In Vercel dashboard → Settings → Domains → Add `finpathnigeria.com`
3. Update DNS at your registrar:
   - A record: `76.76.21.21`
   - CNAME `www`: `cname.vercel-dns.com`
4. SSL certificate auto-generated by Vercel (HTTPS required for PWA)

## STEP 7 — HTTPS (Required for PWA)

PWA features (service worker, install prompt, push notifications) ONLY work over HTTPS.

✅ Vercel → automatic HTTPS
✅ Netlify → automatic HTTPS
✅ Your own server → get free SSL from Let's Encrypt (certbot)

## Enabling Push Notifications (When Backend Ready)

1. Generate VAPID keys:
```bash
npm install web-push
npx web-push generate-vapid-keys
```

2. Add to your backend (Node.js/Express):
```javascript
const webpush = require('web-push');
webpush.setVapidDetails('mailto:hello@finpathnigeria.com', PUBLIC_KEY, PRIVATE_KEY);
// Save subscription from client, call webpush.sendNotification(subscription, payload)
```

3. In `usePWA.js`, uncomment the subscribe block and replace `YOUR_VAPID_PUBLIC_KEY`

4. Send notifications for:
   - Trial expiring (3 days before end)
   - Name change request decision
   - New investment opportunity alerts
   - Monthly financial tip

## Adding Paystack Payments (For Pro Upgrade)

```bash
npm install @paystack/inline-js
```

In your UpgradeModal component:
```javascript
import PaystackPop from '@paystack/inline-js';

const handlePayment = () => {
  const handler = PaystackPop.setup({
    key: 'pk_live_YOUR_PAYSTACK_PUBLIC_KEY',
    email: user.email,
    amount: 250000, // ₦2,500 in kobo
    currency: 'NGN',
    ref: `FP_${Date.now()}`,
    onSuccess: (transaction) => {
      // Upgrade user to Pro in your database
      updateUserPlan(user.id, 'pro');
    },
    onCancel: () => console.log('Payment cancelled'),
  });
  handler.openIframe();
};
```

## Connecting a Real Backend (When Ready)

Replace `localStorage` calls in `AUTH` object with API calls:

```javascript
// Current (localStorage):
AUTH.signup = (data) => { localStorage... }

// Future (API):
AUTH.signup = async (data) => {
  const res = await fetch('https://api.finpathnigeria.com/auth/signup', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(data)
  });
  return res.json();
};
```

Recommended backend stack: **Supabase** (free, Nigerian-compatible, Postgres + auth + storage)
